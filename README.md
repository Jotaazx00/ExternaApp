# ExternaApp

Aplicativo educacional demonstrativo para o Ensino Médio do Colégio Externato.

## Atualização de navegação

- A barra lateral permanece visível em todas as páginas na versão desktop, mantendo a estética navy, amarela e ciano.
- **Painel** e **Laboratório 3D** são áreas independentes.
- O Painel apresenta a visão geral da jornada, métricas, desempenho e histórico.
- Os modelos e controles tridimensionais aparecem exclusivamente no Laboratório 3D e nas missões práticas.
- A navegação continua adaptada para telas menores.

## Executar localmente

Requer Node.js 22 ou superior e pnpm.

```bash
pnpm install
pnpm dev
```

Para gerar a versão de produção:

```bash
pnpm build
```

Os dados do aplicativo são fictícios e ficam salvos apenas no navegador. A troca de perfil simula permissões; não existe autenticação real ou integração com boletim escolar.

As imagens institucionais desta cópia são carregadas do repositório original `qiqisupremacy6-wq/EXTERNAPP`.
